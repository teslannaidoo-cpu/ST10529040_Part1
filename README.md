\## Project Overview

This project focuses on developing a professional five-page website for Durban HomeFix Plumbing. The website is designed to provide customers with clear information about the organisation, its plumbing services, and how to make an enquiry or get in contact.



The website consists of a Home page, About Us page, Services page, Enquiry page and Contact page. It uses HTML for the structure, CSS for the visual design and JavaScript for interactive functionality.



The website is intended to be easy to navigate, responsive across different devices and suitable for homeowners who require reliable plumbing services in Durban and surrounding areas.





















\## Website Goals and Objectives



The main goal of the website is to create a clear and professional online presence for Durban HomeFix Plumbing.



The website aims to:



\- Provide customers with information about the plumbing services offered.

\- Make it easy for customers to submit an enquiry.

\- Provide clear contact information for the business.

\- Make the website simple to navigate across the five main pages.

\- Ensure that the website works well on desktop, tablet and mobile devices.

\- Present the organisation and its services in a professional and trustworthy way.



\### Key Performance Indicators (KPIs)



The success of the website will be measured using the following indicators:



\- Number of enquiries submitted through the website.

\- Number of visitors who use the contact information.

\- Number of visitors viewing the Services page.

\- Successful navigation between the five main pages.

\- Website usability and responsiveness across different devices.



\## Key Features and Functionality



The website includes five main pages: Home, About Us, Services, Enquiry and Contact.



The Home page introduces Durban HomeFix Plumbing and provides navigation to the other pages.



The About Us page provides information about the organisation and its purpose.



The Services page presents the plumbing services offered, including plumbing repairs, blocked drains, leak repairs, pipe repairs and plumbing maintenance.



The Enquiry page contains a form that allows customers to provide their details, select the required service, choose a preferred contact method and describe their plumbing problem.



The Contact page provides the business contact information and allows visitors to get in touch with Durban HomeFix Plumbing.



JavaScript is used to provide client-side interaction for the enquiry and contact forms, including form submission messages and form resetting.



The website uses CSS to provide a consistent visual design and responsive layout across different screen sizes.
